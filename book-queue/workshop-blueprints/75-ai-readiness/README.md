# AI Readiness workshop

**Private blueprint for a 60-minute, noncredit workshop. No registration or release.**

Begin with one assignment that could be finished by AI without showing what a student learned. Use six readiness questions to locate the gaps, rewrite one task, and decide what evidence would demonstrate learning. The outcome is a small, reviewable revision, not an institutional readiness certificate.

The existing [AI Readiness skill](https://github.com/nikbearbrown/ai-readiness) is a separate tool. It can produce audit signals and suggestions, but the teacher reads the evidence and decides what to change. Participants can complete the workshop without installing it or using an LMS.
