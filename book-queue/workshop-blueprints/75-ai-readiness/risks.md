# Risks and fallback

- Use a synthetic exercise or instructor-approved redacted materials only. Do not upload a real course export, student information, assessment banks or supporting records to a model or public service.
- Review outputs against course-specific evidence. The automatic check is not a grade, an institutional certification or an approval. Do not claim that a polished revision produced better learning without measuring it.
- No live LMS action is required. Neither a locally built archive nor a tool validation report proves successful Canvas import. If a later session demonstrates import, use explicit authorization for a sandbox and record the actual result.
- No skill access? Use the provided prompt/output fixture and the same rubric. No tool installation, paid account, grading or enrollment is required.
