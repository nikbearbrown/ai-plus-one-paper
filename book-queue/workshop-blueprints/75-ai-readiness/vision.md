# Vision and audience

Teach educators to redesign learning in their own discipline, rather than add an AI prompt for its own sake. An educator should be able to use the method with or without an agent. The course team owns policy, grades, and approval.

The workshop deliberately changes one assignment. A longer follow-up could apply the method to a module or course, but this session does not attempt a complete course migration, build an export, or validate an institutional standard.
