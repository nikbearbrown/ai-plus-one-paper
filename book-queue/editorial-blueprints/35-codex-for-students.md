# Codex for Students

Private workshop Blueprint • `codex-for-students-ai-one` • 70 minutes • noncredit proposal.

**Audience and prerequisites:** Student programmers who can read simple tests and diffs.

**Case:** A local inventory parser that mishandles a blank line.

## Run of show

- 0–15: Write a three-case behavior contract and a failing test first.
- 15–35: Give Codex only that contract and the disposable fixture; inspect its proposal before accepting.
- 35–55: Compare changed paths against the declared scope and run one withheld case.
- 55–70: Present a concise commit message and include a disclosed limitation.

## Artifact and verification

Patch, failure-before/pass-after receipt and a separate explanation evaluated against a small rubric.

**Boundary:** Use an available authorized Codex interface or a provided transcript/diff. No external writes, real class submissions or assumed model features.
