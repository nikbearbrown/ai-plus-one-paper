# Claude Code for Teachers

Private workshop Blueprint • `claude-code-for-teachers-ai-one` • 75 minutes • noncredit proposal.

**Audience and prerequisites:** Instructors with basic terminal navigation; offline scaffold supplied.

**Case:** A synthetic course handout folder with stale relative links.

## Run of show

- 0–15: Define the allowed paths and independently identify one broken link.
- 15–35: Request a diagnosis and narrow patch in a disposable copy, or inspect a supplied diff.
- 35–60: Approve only the intended edits; check links, unrelated-file hashes and a reset path.
- 60–75: Peer explains where the tool would have needed additional permission.

## Artifact and verification

A teaching-repo patch and acceptance note; demonstrate one link fixed and no changes outside the fixture.

**Boundary:** No real gradebooks, external connections or deployment. Tool availability and permission prompts vary.
