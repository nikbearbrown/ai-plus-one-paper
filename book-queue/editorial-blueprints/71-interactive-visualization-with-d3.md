# Interactive Visualization with D3

Private workshop Blueprint • `interactive-visualization-with-d3-ai-one` • 90 minutes • noncredit proposal.

**Audience and prerequisites:** Developers with JavaScript, HTML and basic chart reading; supply local fixture and offline fallback.

**Case:** A fictional bike-share chart with selection and keyboard controls.

## Run of show

- 0–15: Hand sketch scale, domain, key and empty-state behavior.
- 15–40: Implement a static D3 view on the small dataset, or annotate supplied starter.
- 40–65: Add a filter with keyboard access; inspect AI-proposed refactoring against the original behavior.
- 65–90: Check two filters, empty state, stable marks and a text/table fallback.

## Artifact and verification

One local interactive chart with a fixture, expected-value receipt and accessible alternative; independently verify selected counts.

**Boundary:** An implementation lab, not slide authoring or a general chart-design class. Verify library version and dataset and code licenses before publication.
