# Editorial blueprints

The [catalog](../) links each title to one format-appropriate plan. This directory fills gaps that were not already covered by the [syllabus blueprints](../syllabus-track/blueprints/), [local plans](../local-blueprints/), or [AI Readiness workshop](../workshop-blueprints/75-ai-readiness/).

- **Popular books:** reader, argument, chapter arc, and evidence needed.
- **Courses and textbooks:** learner, prerequisites, chapter sequence, assessable work, and a drafting gate.
- **Workshops:** audience, timed practice, a concrete takeaway, and a check that it works.

For AI Plus One courses, develop at least one discipline-specific AI activity: preserve an independent first attempt, let the learner use AI for a bounded task, and grade the learner’s verification and decisions. Specify the non-AI fallback and what assessment evidence it yields. Mark proposed tool and assessment details for educator review.

These are private planning specifications, not manuscripts or signed Blueprint gates. A listed source is a lead unless the plan records inspection. The catalog's compare and hold statuses remain in force. See the [drafting handoff](../../codex-handoff.md) before using a course plan.

Maintenance: run `python3 book-queue/render-catalog.py` from the repo root after changing the inventory. The `--check` option fails when the catalog is stale, a plan is missing, or a numbered editorial blueprint has no catalog entry.
