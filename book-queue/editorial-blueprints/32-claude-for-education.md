# Claude for Education

Private workshop Blueprint • `claude-for-education-ai-one` • 60 minutes • noncredit proposal.

**Audience and prerequisites:** University instructors comfortable editing a lesson; no terminal.

**Case:** A fictional statistics explanation and a short contrast exercise.

## Run of show

- 0–10: State one learning outcome and write the independent answer.
- 10–25: Ask Claude for two explanations of the same concept, or compare supplied drafts.
- 25–45: Check each against the reference and revise a misleading explanation.
- 45–60: Write a no-AI transfer question and swap it with a partner.
