# Coding Agents and Local Project Workflows (AI Plus One)

**Order 60.** Planning only; not authorization to draft.

## Vision

Bound local coding agents with inspectable permissions, controlled patches and recoverable execution.

**Audience and prerequisites:** Engineers who already review diffs and operate in local shells.

**Source basis:** Queue lists `nikbearbrown/cli-agnostic-ai-tooling-for-local-project-workflows` as primary and `nikbearbrown/prompt-engineering-for-cli-ai-coding-agents; nikbearbrown/prompt-engineering-with-clis; nikbearbrown/claude-for-prompt-engineering; nikbearbrown/claude-cowork` as related. ## Learning architecture and chapter checks

1. **Workspace and authority.** Output: Draw read/write/network boundaries in a mock project. Check: Test that unrelated paths stay untouched.
2. **Plan and patch.** Output: Set checkpoints and constrain edits to an assignment. Check: Review a deliberately excessive proposed patch.
3. **Run and inspect.** Output: Capture safe local test execution and file changes. Check: Find when a command result does not support a summary.
4. **Recover and repeat.** Output: Design interruption, retry and revert behavior. Check: Re-run without changing a clean baseline.

## Assessed deliverable

A local orchestration playbook plus a mock run log and an independently replayed patch workflow. Begin independently; log any AI assistance and independently verify its claims and outputs.
