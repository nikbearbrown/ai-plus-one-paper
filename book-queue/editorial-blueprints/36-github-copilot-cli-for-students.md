# GitHub Copilot CLI for Students

Private workshop Blueprint • `github-copilot-cli-for-students-ai-one` • 60 minutes • noncredit proposal.

**Audience and prerequisites:** Student developers who can read simple shell commands and tests.

**Case:** A toy text report generator with a newline formatting bug.

## Run of show

- 0–10: Identify the expected text exactly and write a comparison case on paper.
- 10–25: Ask Copilot CLI for a diagnosis and proposed commands, or inspect the canned suggestion.
- 25–45: Explain each command before executing in a disposable fixture; reject unrelated actions and check the resulting diff.
- 45–60: Run a second test and explain the remaining risk.

## Artifact and verification

A reviewed diff plus two exact-output checks and a signed-by-learner explanation of which commands were approved.

**Boundary:** No auto-approval, live credentials or dependence on a particular release. Only synthetic local inputs.
