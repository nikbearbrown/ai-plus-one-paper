# Claude Code for Students

Private workshop Blueprint • `claude-code-for-students-ai-one` • 70 minutes • noncredit proposal.

**Audience and prerequisites:** Student programmers familiar with a repository and basic tests.

**Case:** A toy grade-free café order total with an empty-list boundary.

## Run of show

- 0–15: Reproduce a failure and write the expected answer without AI.
- 15–35: Ask Claude Code to propose one minimal change; otherwise use the supplied patch.
- 35–55: Inspect the diff, add one independent regression test, and rerun normal and boundary cases.
- 55–70: Explain the fix and disclose what the agent contributed.

## Artifact and verification

One small patch and actual test receipt; learner explains why the pre-fix test failed and the new boundary still passes.

**Boundary:** Instructor rules govern graded use. No private keys, live accounts or assumptions about hosted tooling.
