## Reader and purpose

**Audience and prerequisites:** New programmers with basic algebra and ability to organize files; no prior coding-agent use required.

**Teaching spine:** Build a readable Python program by predicting behavior, testing evidence and recovering from unexpected inputs.

## Proposed chapter progression

1. **Trace expressions and decisions.** Predict output before running a toy calculator; explain a mismatch in conditional logic.
2. **Define functions with contracts.** Extract discount logic into functions; cover boundaries without copying expected values from output.
3. **Organize collections and files.** Parse a synthetic CSV or JSON file; handle missing, duplicate and malformed records deterministically.
4. **Debug from observable behavior.** Follow an erroneous total with breakpoints or print traces; add a regression test before the repair.
5. **Assemble, test and explain a program.** Deliver a repeatable command with a small set of fixtures and a failure message a new reader can act on.

## Assessed deliverable

A command-line booking report over synthetic records. Grade function boundaries, correct output, input validation, tests including a hidden fixture and a readable explanation of a repaired bug.

Require a first unaided attempt and a checked revision. Any AI assistance is optional unless the source-verified teaching scope specifically calls for it; assess learner judgment from a separate calculation, trace, or test.
