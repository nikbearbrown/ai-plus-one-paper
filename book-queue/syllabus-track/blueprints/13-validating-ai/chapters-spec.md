# Chapter specifications

**Private Blueprint only. Draft route: `existing-book`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Turn fluent text into claims you can check

- **Observable capability:** Write specific claims with scope and limits.
- **Teaching blocks:** claim extraction; source tiers; falsifiers; unsupported statements
- **Original worked example to write:** Split a fictional model-generated report about library demand into five checkable statements.
- **Assessable practice:** Find two wrong inferences even with correct numbers and state required evidence.

## 2. Calibrate a claim about uncertainty

- **Observable capability:** Read reliability and uncertainty without overstating validation.
- **Teaching blocks:** calibration; sample size; intervals; decision thresholds
- **Original worked example to write:** Compare two synthetic warning models with equal accuracy.
- **Assessable practice:** Calculate calibration bins and explain a case that ordinary accuracy misses.

## 3. Test when the setting changes

- **Observable capability:** Design a robustness check preserving intended meaning.
- **Teaching blocks:** perturbations; shift; baseline; failure trace
- **Original worked example to write:** Change the formatting of fictional data-entry cases without altering facts.
- **Assessable practice:** Run paired checks and explain which failure invalidates the original deployment assumption.

## 4. Audit uneven errors

- **Observable capability:** Compare errors and costs across clearly defined groups.
- **Teaching blocks:** denominators; error rates; burden; fairness limits
- **Original worked example to write:** Analyze a hypothetical helpdesk classifier with two workload groups.
- **Assessable practice:** Compute separate errors and justify a reporting decision without causal assumptions.

## 5. Follow an agent’s evidence trail

- **Observable capability:** Diagnose failures and require a handoff or stop rule.
- **Teaching blocks:** tool trace; permission boundary; independent checks; failed-action recovery
- **Original worked example to write:** Trace a toy card-catalog agent that cites a result absent from its tool log.
- **Assessable practice:** Deliver an audit finding with reproduction by benign fixture and explicit release disposition.
