# Learning architecture

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

## Proposed measurable outcomes

- Map user tasks
- construct semantic UI
- test accessibility
- verify a responsive interaction

## Sequencing and final artifact

Establish with map the task before layout, build through the middle worked cases, then apply in test and revise. Final artifact: a form error not announced to the reader with a documented decision and check.

## Assessment and AI Plus One practice

Independent first attempt on the opening exercise: Map an empty, full and error state. Then optionally let AI propose one change; compare it against the independent trace or calculation. Grade evidence quality, correctness on a changed case, and explanation; final demonstration: Write a defect report with expected behavior.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
