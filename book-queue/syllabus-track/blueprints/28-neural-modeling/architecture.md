# Learning architecture

**Private Blueprint only. Draft route: `ready-for-draft-review`. Evidence: `matched-source`. No sign-off.**

## Proposed measurable outcomes

- Build a strong non-neural baseline
- Select an architecture for a stated data structure
- Evaluate a neural model on held-out and shifted data
- Explain model failures using reproducible evidence

## Sequencing and final artifact

Establish baseline, metrics and reproducible environments; build dense, sequential and visual models; apply to a documented comparison across one modest task.

## Assessment and AI Plus One practice

Require a by-hand baseline and test plan before model assistance, then a held-out comparison, seeded experiments and a model limitations card; audit any AI-generated code with invariant checks.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
