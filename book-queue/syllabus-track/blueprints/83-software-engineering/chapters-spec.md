# Chapter specifications

**Private Blueprint only. Draft route: `hold-source`. Evidence: `no-usable-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Turn a request into evidence

- **Observable capability:** Write falsifiable acceptance criteria
- **Teaching blocks:** requirements; scope; edge cases
- **Original worked example to write:** Toy library hold notifications
- **Assessable practice:** Resolve one ambiguous stakeholder request

## 2. Change behavior safely

- **Observable capability:** Build a regression-first change plan
- **Teaching blocks:** design seams; unit/integration tests; fixtures
- **Original worked example to write:** Toy notification retry bug
- **Assessable practice:** Reproduce and correct a planted regression

## 3. Make review independently useful

- **Observable capability:** Write a review that traces evidence
- **Teaching blocks:** change size; maintainability; documentation
- **Original worked example to write:** Synthetic patch with weak validation
- **Assessable practice:** Grade evidence for a claimed fix

## 4. Handoff and evolve

- **Observable capability:** Show how another developer can recover intent
- **Teaching blocks:** decision logs; operations readiness; retrospection
- **Original worked example to write:** Second toy bug on same toy repository
- **Assessable practice:** Repair an adjacent failure from only the handoff and tests
