# Designing Scalable and Reliable Software Services (AI Plus One)

**Private Blueprint only. Draft route: `ready-for-draft-review`. Evidence: `matched-source`. No sign-off.**

Design software backends such as a campus activity feed or a city repair-request service. Start with one service and a database; add caching, queues, or replicas only when the workload and failure requirements justify them. Learn to estimate capacity, specify what users can rely on, and test what happens when dependencies fail.

This book focuses on architecture decisions for an application. The [Distributed Systems blueprint](../16-distributed-systems/) goes deeper into the mechanisms behind ordering, replication, and commit protocols. Compare shared chapters before drafting; the book is not about building AI agents.
