# Chapter specifications

**Private Blueprint only. Draft route: `existing-book`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Frame the decision

- **Observable capability:** Draw a workflow with an owner for every decision
- **Teaching blocks:** goal; state; handoff; baseline
- **Original worked example to write:** Library booking request that lacks a branch
- **Assessable practice:** Locate two choices that should not be delegated

## 2. Decide what the loop may remember

- **Observable capability:** Separate working state from durable evidence
- **Teaching blocks:** state reduction; trace IDs; observation confidence; provenance
- **Original worked example to write:** Two responses for a fictional service catalog record
- **Assessable practice:** Show which result changes state and why

## 3. Define tool boundaries

- **Observable capability:** Write a typed input and output contract
- **Teaching blocks:** schema; scope; stop; uncertainty
- **Original worked example to write:** Look up a synthetic book ID
- **Assessable practice:** Predict a refusal for an unknown ID, then trace it

## 4. Compare two control loops

- **Observable capability:** Explain when a state machine beats a model router
- **Teaching blocks:** routing; bounded retries; decision state; fallback
- **Original worked example to write:** Campus room lookup with two possible buildings
- **Assessable practice:** Replay three cases through both workflows

## 5. Check the trace

- **Observable capability:** Diagnose and correct a false success without expanding privileges
- **Teaching blocks:** invariants; synthetic fixtures; human escalation; replay
- **Original worked example to write:** A completed transcript with no reservation receipt
- **Assessable practice:** Specify the trace fields and acceptance tests
