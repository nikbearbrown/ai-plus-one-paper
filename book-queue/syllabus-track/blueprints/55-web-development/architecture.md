# Learning architecture

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

## Proposed measurable outcomes

- Describe an accessible document and interaction
- Trace update flow across browser, server and storage
- Test validation and recovery on both boundaries
- Defend a deployable feature with receipts and limits.

## Sequencing and final artifact

Establish document, style and browser state; build the server contract and persistence against a vertical feature; apply accessibility and failure checks in an isolated web application deliverable.

## Assessment and AI Plus One practice

Grade semantic keyboard use, state consistency, valid error handling and proof through deterministic tests. Sketch and predict by hand before AI assistance; verify framework suggestions with local contract tests and inspect the result independently.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
