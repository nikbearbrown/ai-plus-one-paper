# Engentic Web Development (AI Plus One)

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

**Proposed spine:** Build an accessible web feature from browser to data store by directing a coding agent, using the repository's real constraints and independently verified acceptance tests to decide what to keep and what is ready for release.

**Proposed reader:** Learners who can read and edit basic code and use a web browser. Begin with an existing small repository; teach the HTTP, data, accessibility, and testing concepts needed to judge a change. No prior experience with a particular framework, coding agent, or host is required.

**Observed syllabus evidence:** The public CS4550/CS5610 Fall 2026 syllabus snapshot (p. 1; see [source register](sources.tsv)) connects markup and styles, interactive client state, an API, and a document database in a deployable full-stack artifact. Its specific tools are source examples, not requirements here. The Engentic workflow, synthetic project, exercises, and release controls are proposed editorial content, not observed syllabus practices.
