# Chapter specifications

**Private Blueprint only. Draft route: `ready-for-draft-review`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Decide what an edge means

- **Observable capability:** Build a graph without silently equating distinct relationships.
- **Teaching blocks:** Representations; sampling; directed and weighted edges; provenance.
- **Original worked example to write:** Construct alternate collaboration graphs from synthetic volunteer assignments.
- **Assessable practice:** Compare edge counts and explain a change caused by a modeling decision.

## 2. Verify network measurements

- **Observable capability:** Compute and check connectivity, clustering and spectral behavior.
- **Teaching blocks:** Paths; components; clustering; eigenvector or spectral diagnostics.
- **Original worked example to write:** Compare a cycle and two cliques linked by a bridge.
- **Assessable practice:** Match hand results to sparse implementation and identify one numerical limitation.

## 3. Detect structure without fooling yourself

- **Observable capability:** Compare communities to a controlled graph null.
- **Teaching blocks:** Degree-preserving nulls; modularity resolution; partitions; uncertainty across seeds.
- **Original worked example to write:** Find how groups appear after biased sampling of a synthetic contact network.
- **Assessable practice:** Run repeated seeded trials and distinguish stable clusters from chance structure.

## 4. Model growth and dynamics

- **Observable capability:** Compare a network process across distinct graph-generating mechanisms.
- **Teaching blocks:** Attachment; assortativity; simple diffusion; parameter sweeps.
- **Original worked example to write:** Compare a benign information-sharing model on random and clustered graphs.
- **Assessable practice:** Evaluate an outcome distribution while controlling mean degree and reporting uncertainty.

## 5. Scale and reproduce

- **Observable capability:** Publish a reproducible, resource-conscious network study.
- **Teaching blocks:** Sparse memory; time profiling; experiment manifests; visualization.
- **Original worked example to write:** Benchmark path summaries on increasing synthetic networks under memory limits.
- **Assessable practice:** Submit a notebook and data receipt that another person can run on a laptop.
