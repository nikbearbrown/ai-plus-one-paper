# Learning architecture

**Private Blueprint only. Draft route: `existing-book`. Evidence: `matched-source`. No sign-off.**

## Proposed measurable outcomes

- Write a task specification and output contract
- Construct baseline and varied prompts with explicit evidence requirements
- Evaluate outputs independently on fixtures and adversarial-free negative cases
- Constrain a benign agent’s tools and reject unsupported actions
- Report sensitivity, limits and revisions for reuse

## Sequencing and final artifact

Assimilate existing broad manuscript and offline-first course labs: establish model limits/contracts, build structured prompts and retrieval/tools, apply comparative test and bounded agent trace. Place proprietary tools in replaceable modules.

## Assessment and AI Plus One practice

Attempt the task and expected answer independently, then compare prompt variants on frozen development/holdout examples. Optional AI can generate prompts; independent schema and evidence checks, reachability and human transfer determine quality.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
