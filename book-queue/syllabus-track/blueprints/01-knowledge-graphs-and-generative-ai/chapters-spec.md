# Chapter specifications

**Private Blueprint only. Draft route: `reuse-private-pilot`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Ask before building

- **Observable capability:** Set a competency question, identity policy and unknown-answer rule.
- **Teaching blocks:** entity keys; evidence ledger; expected result; unknowns
- **Original worked example to write:** Reuse pilot’s two same-name people and one library workshop.
- **Assessable practice:** Write a new question and hand-label the expected answers when approval is missing.

## 2. Query a property graph

- **Observable capability:** Trace and query a directed, typed pattern.
- **Teaching blocks:** traversal direction; types; properties; accepted status
- **Original worked example to write:** Reuse pilot’s confirmed workshop-approval pattern.
- **Assessable practice:** Add a decoy path and explain why a valid query excludes it.

## 3. Query the same question in RDF

- **Observable capability:** Represent and retrieve the same relationship without losing provenance.
- **Teaching blocks:** IRIs; literals; triples; basic graph patterns
- **Original worked example to write:** Reuse pilot’s approval record modeled as a resource rather than a relationship field.
- **Assessable practice:** Submit the triple set and answer table; explain disagreement with a naïve rewrite.

## 4. Inference is not validation

- **Observable capability:** Predict an entailment and separately diagnose a constraint failure.
- **Teaching blocks:** subclass; open-world reasoning; SHACL; trace
- **Original worked example to write:** Reuse the workshop subclass plus a promotion without a required date.
- **Assessable practice:** Draw two separate output tables and classify a new missing-field case.

## 5. Build a graph from imperfect evidence

- **Observable capability:** Resolve a candidate identity while preserving uncertainty.
- **Teaching blocks:** entity resolution; normalized evidence; merge thresholds; graph metrics
- **Original worked example to write:** Reuse the pilot’s two names and an unlinked experience claim.
- **Assessable practice:** Produce a merge ledger for a third record and explain one false-merge consequence.

## 6. Retrieve for generation

- **Observable capability:** Pick a retrieval route and verify claim support.
- **Teaching blocks:** local lookup; collection summaries; evidence citations; abstention
- **Original worked example to write:** Reuse pilot’s single answer versus corpus overview contrast.
- **Assessable practice:** Evaluate a new question using direct search and graph retrieval; mark unsupported claims.

## 7. Defend a design

- **Observable capability:** Choose a design using explicit baselines and regressions.
- **Teaching blocks:** comparative evaluation; failure contract; regression; oral defense
- **Original worked example to write:** Reuse the duplicate-name regression and false-confidence case.
- **Assessable practice:** Run a new ambiguity case; submit reasoned keep/change decision with fixture, results and limits.
