# Chapter specifications

**Private Blueprint only. Draft route: `existing-book`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Put one decision at the center

- **Observable capability:** Convert a vague dashboard goal into a measurable reader question.
- **Teaching blocks:** audience; claim; numerator and denominator; chart task
- **Original worked example to write:** Decide which two fictional library branches have longer median waiting times.
- **Assessable practice:** Write a comparison question and identify the data that cannot answer it.

## 2. Choose an encoding the data can support

- **Observable capability:** Explain why one encoding preserves the needed comparison.
- **Teaching blocks:** position; scale; sorting; uncertainty
- **Original worked example to write:** Show unequal annual sample sizes on a two-panel comparison.
- **Assessable practice:** Sketch two encodings and trace which exaggerates a small difference.

## 3. Account for each plotted value

- **Observable capability:** Recompute display values from documented inputs.
- **Teaching blocks:** aggregation; units; missingness; validation checks
- **Original worked example to write:** Using a small Python table fixture, audit an inflated completion rate in a toy volunteer table.
- **Assessable practice:** Deliver corrected data and cross-check three displayed marks.

## 4. Guide attention without hiding evidence

- **Observable capability:** Design annotation and accessibility that survive neutral presentation.
- **Teaching blocks:** hierarchy; accessible palette; alt text; labels
- **Original worked example to write:** Add a meaningful and not overstated callout to a branch chart.
- **Assessable practice:** Conduct a five-question read test and write equivalent text for a screen-reader user.

## 5. Publish a defensible visual story

- **Observable capability:** Assemble reproducible, layered visuals and an evidence receipt.
- **Teaching blocks:** narrative sequence; figure sourcing; revision audit; scope
- **Original worked example to write:** Present fictional archive usage in two figures and a short caption sequence.
- **Assessable practice:** Submit an annotated chart proof, calculation ledger and one revision tested with a new example.
