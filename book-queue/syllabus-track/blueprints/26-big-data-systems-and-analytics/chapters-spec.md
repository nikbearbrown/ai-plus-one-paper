# Chapter specifications

**Private Blueprint only. Draft route: `hold-source`. Evidence: `tentative-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Set the Decision and Evidence Boundary

- **Observable capability:** Define what can support a claimed analytic output.
- **Teaching blocks:** source provenance; quality assumptions; scope
- **Original worked example to write:** A fictional nonprofit tracks changes in grant commitments.
- **Assessable practice:** Map three sources to claims and mark unsupported fields.

## 2. Prepare and Reconcile Data

- **Observable capability:** Construct a repeatable, validated event-to-summary pipeline.
- **Teaching blocks:** batch transformations; deduplication; quality checks
- **Original worked example to write:** A duplicate event inflates a fictional funding dashboard.
- **Assessable practice:** Write row-count and sum checks and demonstrate detection.

## 3. Evaluate a Baseline and an Assisted Variant

- **Observable capability:** Design a bounded comparison rather than trust fluent output.
- **Teaching blocks:** baseline; test set; quality and failure cases
- **Original worked example to write:** A helper classifies synthetic grant notes into reporting categories.
- **Assessable practice:** Compare against reference labels and explain error modes.

## 4. Design for Reviewable Operations

- **Observable capability:** Measure the tradeoffs and document the review boundary.
- **Teaching blocks:** latency; cost; traceability; human review gates
- **Original worked example to write:** A budget alert must be reviewed when sources disagree.
- **Assessable practice:** Track the evidence chain and propose a usable fallback.
