# Chapter specifications

**Private Blueprint only. Draft route: `existing-book`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Frame the experience

- **Observable capability:** Defend one design choice against an alternative
- **Teaching blocks:** problem; task; counterproposal; evaluation
- **Original worked example to write:** A campus advising intake tool
- **Assessable practice:** Build and compare two journey hypotheses

## 2. Plan information architecture

- **Observable capability:** Show how hierarchy and labeling support a critical journey
- **Teaching blocks:** content model; navigational labels; recovery; alternatives
- **Original worked example to write:** Two advising resources are confused because their labels match
- **Assessable practice:** Compare alternatives and document impact on a mock task

## 3. Design a reusable interface

- **Observable capability:** Document component contracts and variant behavior
- **Teaching blocks:** tokens; components; states; traceability
- **Original worked example to write:** An appointment card with pending status
- **Assessable practice:** Write an interaction acceptance test for keyboard use

## 4. Conduct implementation

- **Observable capability:** Delegate bounded work and assess its change
- **Teaching blocks:** design-to-code; diffs; model limits; human ownership
- **Original worked example to write:** A coding agent proposes a draft intake panel
- **Assessable practice:** Predict risk then inspect a synthetic diff against design

## 5. Defend the experience

- **Observable capability:** Link evaluation to revision
- **Teaching blocks:** critical journey; failure path; evidence; portfolio
- **Original worked example to write:** A test person abandons a confusing step in a fictional case
- **Assessable practice:** Build an eval dossier with limits and design changes
