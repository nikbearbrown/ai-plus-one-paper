# Chapter specifications

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Predict before execution

- **Observable capability:** Trace assignments and basic conditionals in concrete cases
- **Teaching blocks:** values and names; branch conditions; traces; invalid input
- **Original worked example to write:** A small volunteer sign-up rule checks available places before accepting a request.
- **Assessable practice:** Predict four outcomes before running and correct one discrepancy in the hand trace.

## 2. Express a repeated pattern

- **Observable capability:** Choose a representation and explain how a loop updates it
- **Teaching blocks:** collections; iteration; counters; loop invariant
- **Original worked example to write:** A mock pantry aggregates a sequence of delivered box counts.
- **Assessable practice:** Extend a starter specification for empty and repeated observations, then supply trace tables.

## 3. Divide the task at the right seam

- **Observable capability:** Write function contracts and examples that expose missing cases
- **Teaching blocks:** decomposition; inputs and outputs; preconditions; examples
- **Original worked example to write:** A pretend school space allocator separates availability from booking eligibility.
- **Assessable practice:** Write two contracts and explain where a specified edge case belongs.

## 4. Test, revise, and defend a program

- **Observable capability:** Validate a small program and explain one changed prediction
- **Teaching blocks:** unit tests; debugging; edge cases; independent explanation
- **Original worked example to write:** A fictional reading challenge awards tokens based on a list of sessions.
- **Assessable practice:** Implement a small solution, predict tests first, and explain an observed bug without the tool.
