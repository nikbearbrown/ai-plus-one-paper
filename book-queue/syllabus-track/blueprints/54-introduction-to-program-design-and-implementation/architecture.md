# Learning architecture

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

## Proposed measurable outcomes

- Trace a program by hand
- Define inputs, outputs and invariants for a small function
- Decompose a requirement into testable units
- Use tests and explanation to justify a complete small program.

## Sequencing and final artifact

Establish tracing and data representation, build decomposition and test design, then apply those skills in a final small program plus an independent skill explanation. Treat chapter sequence as proposed pending full skill-list review.

## Assessment and AI Plus One practice

Use repeatable unaided micro-assessments and a final oral or paper trace. AI can suggest test cases after a learner writes and predicts their own; assess explanation, correct cases and independently verified improvements.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
