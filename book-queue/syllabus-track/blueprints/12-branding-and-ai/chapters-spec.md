# Chapter specifications

**Private Blueprint only. Draft route: `existing-book`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Set a brand promise you can test

- **Observable capability:** State identity, audience, evidence and exclusions.
- **Teaching blocks:** positioning; stakeholder distinction; distinctiveness; evidence
- **Original worked example to write:** Define brand constraints for a fictional neighborhood tool library.
- **Assessable practice:** Create two candidate promises and adjudicate them against an original small persona set.

## 2. Translate strategy into a design language

- **Observable capability:** Link visual and verbal rules to intended perceptions.
- **Teaching blocks:** tone; type hierarchy; tokens; reusable constraints
- **Original worked example to write:** Encode a community workshop brand in reusable color and spacing tokens.
- **Assessable practice:** Produce a one-page style rationale and accessibility checklist.

## 3. Direct bounded variations

- **Observable capability:** Generate and compare channel options while retaining control.
- **Teaching blocks:** source permissions; prompt boundary; alternatives; evaluation
- **Original worked example to write:** Adapt an original library event announcement to two format constraints.
- **Assessable practice:** Reject one superficially attractive alternative with a reproducible criterion.

## 4. Check what people actually understand

- **Observable capability:** Collect qualitative evidence without overclaiming permanence.
- **Teaching blocks:** brief test; semantic consistency; contrast; repair
- **Original worked example to write:** Test whether invitees can identify sign-up and eligibility from a pretend poster.
- **Assessable practice:** Run an unaided test on a contrast version and document one repair.

## 5. Hand off a consistent campaign system

- **Observable capability:** Deliver reusable assets and explicit review responsibility.
- **Teaching blocks:** version history; guide and QA; accountability; optional bounded tool prototype
- **Original worked example to write:** Make three coordinated materials and one intentionally wrong version.
- **Assessable practice:** Supply a check sheet and defend why the outlier should not ship.
