# Learning architecture

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

## Proposed measurable outcomes

- Define a narrow user task
- wire model and deterministic logic
- test no-answer behavior
- document a release limit

## Sequencing and final artifact

Establish with start from an acceptance case, build through the middle worked cases, then apply in package a testable app. Final artifact: a static mock approval interface with a documented decision and check.

## Assessment and AI Plus One practice

Independent first attempt on the opening exercise: Write expected outputs for three requests. Then optionally let AI propose one change; compare it against the independent trace or calculation. Grade evidence quality, correctness on a changed case, and explanation; final demonstration: Demonstrate a failing case and corrected behavior.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
