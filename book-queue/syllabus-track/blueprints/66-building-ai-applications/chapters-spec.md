# Chapter specifications

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Start from an acceptance case

- **Observable capability:** State value without a model first
- **Teaching blocks:** user task; input; output; non-goals
- **Original worked example to write:** A sign-up FAQ with a fixed schedule
- **Assessable practice:** Write expected outputs for three requests

## 2. Choose how much code to own

- **Observable capability:** Compare a visual workflow with a code-backed adapter
- **Teaching blocks:** visual automation; low-code boundaries; portability; review
- **Original worked example to write:** One toy FAQ route in a diagram and pseudocode
- **Assessable practice:** Show the same failure case in both and justify one

## 3. Connect a bounded model step

- **Observable capability:** Keep validation outside generation
- **Teaching blocks:** schema; model adapter; invalid output; mock
- **Original worked example to write:** Structured draft of a workshop reply
- **Assessable practice:** Hand-check one malformed output and fallback

## 4. Design the no-answer path

- **Observable capability:** Distinguish unknown from error
- **Teaching blocks:** certainty; retry; explanation; escalation
- **Original worked example to write:** An event date not present in source data
- **Assessable practice:** Add an answerable/unknown pair and predict returns

## 5. Package a testable app

- **Observable capability:** Present reproducible evidence and remaining failures
- **Teaching blocks:** fixture; tests; accessibility; disclosure
- **Original worked example to write:** A static mock approval interface
- **Assessable practice:** Demonstrate a failing case and corrected behavior
