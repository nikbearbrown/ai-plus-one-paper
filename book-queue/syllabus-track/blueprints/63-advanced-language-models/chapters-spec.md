Each entry is a proposed chapter, not drafted prose.

## 1. Establish the baseline

- **Observable capability:** Predeclare correctness metrics and evaluation data
- **Teaching blocks:** held-out cases; labels; uncertainty; baseline
- **Original worked example to write:** Short fictional library notices
- **Assessable practice:** Define answer and abstain cases independently

## 2. Trace a model computation

- **Observable capability:** Explain one controlled context effect without conflating model parameters with input
- **Teaching blocks:** tokens; attention intuition; parameter vs context; scaling limits
- **Original worked example to write:** Same words under two fictional context orders
- **Assessable practice:** Predict which information is available without claiming actual model output

## 3. Change context, not the model

- **Observable capability:** Evaluate retrieval and context selection
- **Teaching blocks:** chunking; evidence; context budgets; confounds
- **Original worked example to write:** Two conflicting notice versions
- **Assessable practice:** Separate retrieval failure from answer failure

## 4. Change behavior deliberately

- **Observable capability:** Distinguish prompt, structured output and adaptation decisions
- **Teaching blocks:** prompt constraints; output structure; adaptation; risk
- **Original worked example to write:** A model formats invented due dates
- **Assessable practice:** Decide whether a change addresses the failure mode

## 5. Read the result as evidence

- **Observable capability:** Identify a comparison that supports the conclusion
- **Teaching blocks:** paired tests; error slices; latency; uncertainty
- **Original worked example to write:** Same questions under two methods
- **Assessable practice:** Write a bounded conclusion and a counterexample
