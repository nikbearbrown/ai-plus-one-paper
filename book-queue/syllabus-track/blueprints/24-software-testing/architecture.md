# Learning architecture

**Private Blueprint only. Draft route: `hold-source`. Evidence: `no-usable-source`. No sign-off.**

## Proposed measurable outcomes

- Derive tests from a stated contract
- Find untested behavioral boundaries
- Choose appropriate verification levels
- Support a release recommendation with defect evidence

## Sequencing and final artifact

Establish test oracles and boundaries; build unit and contract test choices; apply independent defect experiments and review a test dossier.

## Assessment and AI Plus One practice

Grade a handwritten test inventory before tool use, reproducible failures, regression tests and one reasoned risk acceptance; re-run AI-suggested test cases and remove unsupported assertions.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
