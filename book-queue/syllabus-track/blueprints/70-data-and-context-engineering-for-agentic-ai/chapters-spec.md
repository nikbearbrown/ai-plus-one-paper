# Chapter specifications

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Turn a question into a data system

- **Observable capability:** Define the analytical unit and ownership
- **Teaching blocks:** question; data contract; batch/stream; latency
- **Original worked example to write:** A synthetic walkway count dashboard
- **Assessable practice:** Compare delay requirements by stakeholder use

## 2. Assemble and test authorized context

- **Observable capability:** Build filtered context whose evidence remains traceable
- **Teaching blocks:** selection; freshness; permissions; abstention
- **Original worked example to write:** A campus-hours assistant sees an outdated notice and current map
- **Assessable practice:** Define and independently check evidence selection and no-answer behavior

## 3. Check causal and predictive claims

- **Observable capability:** Choose an evaluation suited to the question
- **Teaching blocks:** leakage; confounding; forecasting; uncertainty
- **Original worked example to write:** A mock event changes visitor counts
- **Assessable practice:** Explain why prediction cannot establish causation

## 4. Compare compute and storage plans

- **Observable capability:** Model one cost and reproducibility tradeoff
- **Teaching blocks:** storage; transforms; versioning; workload
- **Original worked example to write:** An hourly dataset grows by a fixed fictional factor
- **Assessable practice:** Show two layouts with testable assumptions

## 5. Monitor and communicate

- **Observable capability:** Design failure signals and communicate limits
- **Teaching blocks:** drift; reproducibility; incidents; visualization
- **Original worked example to write:** A source stops sending a daily partition
- **Assessable practice:** Write a stop rule and a truthful dashboard state
