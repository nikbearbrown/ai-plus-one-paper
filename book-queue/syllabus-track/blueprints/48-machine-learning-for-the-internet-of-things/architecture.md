# Learning architecture

**Private Blueprint only. Draft route: `hold-source`. Evidence: `tentative-source`. No sign-off.**

## Proposed measurable outcomes

- Design a leakage-resistant sensor-data split
- Compare an established baseline to a pretrained-model alternative with common metrics
- Report uncertainty and operating-point tradeoffs
- Defend a reproducible study claim and a safe deployment boundary

## Sequencing and final artifact

Establish sensor labeling and temporal dependence; build a leakage-resistant baseline before comparing a supplied pretrained or simulated alternative; apply this to a methods-first study memo, including optional edge feasibility.

## Assessment and AI Plus One practice

Grade split rationale, a baseline comparison, metric interpretation, and safe fallback. Calculate simple metrics by hand first, let AI draft analysis hints, then reproduce counts against original labeled records. Require a methods memo with predeclared baselines, repeat runs and a falsifying condition; score valid negative results equally.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
