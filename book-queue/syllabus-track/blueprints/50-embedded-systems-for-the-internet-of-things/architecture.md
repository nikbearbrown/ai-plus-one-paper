# Learning architecture

**Private Blueprint only. Draft route: `ready-for-draft-review`. Evidence: `matched-source`. No sign-off.**

## Proposed measurable outcomes

- Build a state machine for a low-stakes device
- Calculate a simple sampling and memory budget
- Predict scheduler and timing effects
- Verify fail-safe transitions using scripted simulator inputs.

## Sequencing and final artifact

Establish loop and device state; build timing and memory constraints; apply failures to a simulator capstone with a trace and a bounded safety argument.

## Assessment and AI Plus One practice

Grade a hand-traced state table, resource calculations, edge-case coverage and an explanation without AI. AI may suggest transition tests, but learners must compare them against their locked specification and simulator results.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
