# Chapter specifications

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Set expectations

- **Observable capability:** Make capability limits legible at point of action
- **Teaching blocks:** promise; state; target user; copy
- **Original worked example to write:** An AI summary of workshop rules
- **Assessable practice:** Draft an interface warning with a user action

## 2. Use AI in the UX process without inventing participants

- **Observable capability:** Judge alternative drafts against real or explicitly synthetic observations
- **Teaching blocks:** research planning; synthesis limits; prototype variants; evidence labeling
- **Original worked example to write:** AI suggests categories for fictional feedback cards
- **Assessable practice:** Independently code the cards first and explain a rejected category

## 3. Show uncertainty through choices

- **Observable capability:** Design recoverable alternatives to unsupported confidence
- **Teaching blocks:** ambiguity; evidence; option presentation; refusals
- **Original worked example to write:** Two workshops with similar names
- **Assessable practice:** Prototype clarification and verify task completion

## 4. Design a correction

- **Observable capability:** Keep user edits and reversal possible
- **Teaching blocks:** editable drafts; reversible action; provenance; feedback
- **Original worked example to write:** An assistant assigns a wrong room label
- **Assessable practice:** Demonstrate cancel, edit and review states

## 5. Test mental models

- **Observable capability:** Separate pleasing UI from calibrated confidence
- **Teaching blocks:** task test; explanation; failure cases; accessibility
- **Original worked example to write:** Mock test with fictional participant responses
- **Assessable practice:** Explain what the observations can and cannot support
