# Chapter specifications

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Set expectations

- **Observable capability:** Make capability limits legible at point of action
- **Teaching blocks:** promise; state; target user; copy
- **Original worked example to write:** An AI summary of workshop rules
- **Assessable practice:** Draft an interface warning with a user action

## 2. Use AI in the UX process without inventing participants

- **Observable capability:** Judge alternative drafts against real or explicitly synthetic observations
- **Teaching blocks:** research planning; synthesis limits; approved-frame inspection via Figma MCP; evidence labeling
- **Original worked example to write:** The designer manually maps a fictional workshop prototype in Figma, then asks an agent to inspect one approved frame and flag only missing clarification states; findings are draft annotations tied to visible evidence
- **Assessable practice:** Independently inspect the baseline first, specify the permitted frame and task, and reject one unsupported agent annotation; when MCP is unavailable use an approved export and the same checklist

## 3. Show uncertainty through choices

- **Observable capability:** Design recoverable alternatives to unsupported confidence
- **Teaching blocks:** ambiguity; evidence; option presentation; refusals
- **Original worked example to write:** Two workshops with similar names
- **Assessable practice:** Prototype clarification, refusal and a safe next action; have a human run the same ambiguous case against the manual baseline and the agent-assisted variant

## 4. Design a correction

- **Observable capability:** Keep user edits and reversal possible
- **Teaching blocks:** editable drafts; reversible action; provenance; feedback
- **Original worked example to write:** An assistant assigns a wrong room label
- **Assessable practice:** Demonstrate cancel, edit and review states on both variants. Write a handoff with state links, unresolved gaps and who must verify each condition; approve any write separately

## 5. Test mental models

- **Observable capability:** Separate pleasing UI from calibrated confidence
- **Teaching blocks:** task test; explanation; failure cases; accessibility
- **Original worked example to write:** A human walkthrough of a workshop assistant with scripted edge cases and clearly labeled fictional responses used as teaching fixtures, not participant evidence
- **Assessable practice:** Show whether a human can spot uncertainty, understand refusal and complete recovery without help. Log baseline versus assisted observations, and distinguish scripted checks from actual participant research
