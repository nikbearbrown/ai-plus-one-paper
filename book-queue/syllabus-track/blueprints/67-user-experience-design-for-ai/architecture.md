# Learning architecture

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

## Proposed measurable outcomes

- Map user and model responsibility
- design refusal/recovery
- evaluate trust calibration
- Revise from findings and distinguish what a Figma baseline shows from what a bounded MCP-assisted critique adds.
- Specify what an agent may inspect, annotate or prepare for handoff, then verify its claims against prototype states and a human walkthrough.

## Sequencing and final artifact

Establish with set expectations, build through the middle worked cases, then apply in test mental models. Final artifact: a manually designed Figma baseline, an optional agent-assisted comparison, and a handoff packet with a documented design decision, state checks and limits.

## Assessment and AI Plus One practice

Independent first attempt on the opening exercise: Draft an interface warning with a user action. Then decide which specific question, if any, an agent should answer. Use Figma MCP only for an approved frame: inspect read-only, propose annotations for review, and prepare a handoff draft. Do not write into the source frame without explicit permission; if approved, limit annotations to an authorized duplicate or review layer. Compare against the manual Figma baseline on the same cases. A human must walk through honest uncertainty, a justified refusal, and recovery or reversal before signing off. If access is denied or MCP is unavailable, use an approved static export or provided synthetic wireframe and manually prepare the same handoff. Grade evidence quality, correctness on a changed case, and explanation; final demonstration: Explain what the observations can and cannot support.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
