# Learning architecture

**Private Blueprint only. Draft route: `ready-for-draft-review`. Evidence: `matched-source`. No sign-off.**

## Proposed measurable outcomes

- Derive a relational schema from stated requirements
- Normalize a schema and justify constraints
- Write SQL that correctly answers multi-table questions
- Test integrity during updates and migrations

## Sequencing and final artifact

Establish entities, grain and requirements; build normalized SQL and transaction reasoning; apply through a small relational application with a defensible alternate model when useful.

## Assessment and AI Plus One practice

Grade independent schema sketch, dependency reasoning and query predictions, then executable constraints and adversarial fixture outcomes; compare AI feedback to manually derived row counts.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
