# Chapter specifications

**Private Blueprint only. Draft route: `compare-scope`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Set the optical requirement

- **Observable capability:** Express an imaging goal as measurable quantities
- **Teaching blocks:** field; magnification; working distance; limits
- **Original worked example to write:** A model display magnifier
- **Assessable practice:** State acceptable image size and distance

## 2. Choose a second optical instrument

- **Observable capability:** Trace the input and measured output for two instrument types
- **Teaching blocks:** telescope rays; dispersion; polarization; calibration
- **Original worked example to write:** Compare an angular target and a colored lamp on paper
- **Assessable practice:** Explain which instrument and observable would discriminate two hypotheses

## 3. Trace a first-order design

- **Observable capability:** Predict image placement and sign
- **Teaching blocks:** paraxial approximation; ray pairs; thin lens; sign convention
- **Original worked example to write:** One thin lens and a printed target
- **Assessable practice:** Check prediction with a geometric ray sketch

## 4. Budget prototype error

- **Observable capability:** Quantify which alignment uncertainty matters
- **Teaching blocks:** spacing; decenter; sensitivity; uncertainty
- **Original worked example to write:** A lens holder shifts by an illustrative amount
- **Assessable practice:** Compare two tolerances with the same budget

## 5. Plan the bench test

- **Observable capability:** Connect failure observations to next design step
- **Teaching blocks:** calibration; image capture; repeatability; uncertainty
- **Original worked example to write:** Compare centered and shifted target images
- **Assessable practice:** Draft a measurement sheet and rejection condition
