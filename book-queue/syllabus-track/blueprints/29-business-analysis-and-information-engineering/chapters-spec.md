# Chapter specifications

**Private Blueprint only. Draft route: `ready-for-draft-review`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Frame and Elicit

- **Observable capability:** Distinguish a problem, a proposed solution and actual evidence.
- **Teaching blocks:** stakeholders; interviews; competing goals; assumptions
- **Original worked example to write:** A volunteer intake team reports long waits and duplicate paperwork.
- **Assessable practice:** Draft a neutral interview plan and identify conflict between two goals.

## 2. Model Current and Proposed Work

- **Observable capability:** Represent the process and identify which handoffs create delays.
- **Teaching blocks:** workflow; actors; handoffs; exception paths
- **Original worked example to write:** A repair cafe must allocate limited spots and handle no-shows.
- **Assessable practice:** Compare as-is and proposed flows against one exception.

## 3. Turn Needs into Testable Requirements

- **Observable capability:** Trace each requirement to the need and its acceptance evidence.
- **Teaching blocks:** requirements; UML or process views; priorities; acceptance criteria
- **Original worked example to write:** A bilingual community form must preserve a coordinator’s review step.
- **Assessable practice:** Create a traceability table and a testable acceptance scenario.

## 4. Evaluate Alternatives and Tradeoffs

- **Observable capability:** Justify a solution using cost, usability and implementation constraints.
- **Teaching blocks:** alternatives; outcome metrics; decision matrices; uncertainty
- **Original worked example to write:** The team compares adjusting a shared inbox with building a queue interface.
- **Assessable practice:** Make a reasoned recommendation and state what evidence would reverse it.

## 5. Plan Adoption and Handoff

- **Observable capability:** Communicate an implementable change and how to measure success.
- **Teaching blocks:** sequence; roles; training; rollback and monitoring
- **Original worked example to write:** A library pilot shifts to an appointment-only tool-lending workflow.
- **Assessable practice:** Write a phased pilot plan with acceptance measures and a fallback.
