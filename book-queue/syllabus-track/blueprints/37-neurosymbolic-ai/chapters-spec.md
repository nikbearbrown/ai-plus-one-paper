# Chapter specifications

**Private Blueprint only. Draft route: `ready-for-draft-review`. Evidence: `matched-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Formalize engineering requirements

- **Observable capability:** Express testable system requirements and identify missing premises.
- **Teaching blocks:** Predicates; grounding; entailment; unknowns.
- **Original worked example to write:** A fictional campus room design must satisfy wheelchair clearance and be traceable to stakeholder needs.
- **Assessable practice:** Prove two derived facts and identify one unknown that blocks a recommendation.

## 2. Validate learned proposals against facts

- **Observable capability:** Reject or abstain on an LLM-generated proposal with explicit checks.
- **Teaching blocks:** Ontology links; query provenance; candidate extraction; validator boundaries.
- **Original worked example to write:** Evaluate a drafted floor-plan description against a synthetic inventory and known clearances.
- **Assessable practice:** Classify three proposals as pass, fail or insufficient evidence, and trace every conclusion.

## 3. Use constraints and explain failures

- **Observable capability:** Diagnose a conflict or unsupported result using an inference trace.
- **Teaching blocks:** Consistency checking; solver feasibility; counterexamples; provenance.
- **Original worked example to write:** Find the conflicting constraints that make a fictitious lab schedule infeasible.
- **Assessable practice:** Explain an unsatisfiable core and revise one constraint without weakening a required safety margin.

## 4. Measure the hybrid against alternatives

- **Observable capability:** Make an evidence-backed case for or against hybridization.
- **Teaching blocks:** Symbolic and learned baselines; challenge cases; ablation; limits.
- **Original worked example to write:** Compare three ways to recommend accessible fictional lab spaces.
- **Assessable practice:** Design a test set separating unknown facts from prediction errors and write a controlled result.
