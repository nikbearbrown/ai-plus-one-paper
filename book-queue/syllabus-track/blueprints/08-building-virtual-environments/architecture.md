# Learning architecture

**Private Blueprint only. Draft route: `existing-book`. Evidence: `tentative-source`. No sign-off.**

## Proposed measurable outcomes

- Place assets using frames and scale
- Implement movement and interaction with explicit collision layers
- Evaluate navigation, visibility and visual accessibility
- Validate agent-produced scene changes using inspectable traces, accessibility and measured frame constraints

## Sequencing and final artifact

Assimilation path: establish scene graph and spatial references, build assets/lighting and interaction, apply an evaluated guided scene. Use generic 3D principles before optional engine implementation.

## Assessment and AI Plus One practice

Build a small blockout and draw transforms without AI; optional tool assistance on a single mesh or behavior; independently walk all routes, test collisions and profiled frames. Grade spatial correctness, interaction and reproducibility, not visual polish alone.

Require a first attempt without AI; document any bounded AI assistance and independently check consequential outputs against evidence. These are original assessment recommendations, not institutional assignments or grading policy.
