# Chapter specifications

**Private Blueprint only. Draft route: `existing-book`. Evidence: `tentative-source`. No sign-off.**

Each entry is a proposed chapter, not drafted prose.

## 1. Make a scene you can reason about

- **Observable capability:** Use local/global coordinates and units consistently.
- **Teaching blocks:** scene trees; transforms; instances; scale tests
- **Original worked example to write:** Place a fictional museum sign relative to a gallery doorway.
- **Assessable practice:** Correct an off-axis import and show labeled coordinate checks.

## 2. Build a readable environment

- **Observable capability:** Choose lighting and assets that communicate space and affordance.
- **Teaching blocks:** blocking; sightlines; materials; contrast
- **Original worked example to write:** Model a small exhibit with distinguishable paths without relying on color.
- **Assessable practice:** Change only three parameters and show why route cues improved.

## 3. Design movement and collision

- **Observable capability:** Differentiate visual geometry, physics and interaction target.
- **Teaching blocks:** colliders; layers; input; triggers
- **Original worked example to write:** Create a one-way gate test using simple shapes and known movement speeds.
- **Assessable practice:** Demonstrate a collider/trigger mismatch and produce a replayable fix.

## 4. Connect actions to state

- **Observable capability:** Specify cues and transitions that survive unusual input.
- **Teaching blocks:** interaction prompt; local state; feedback; failure state
- **Original worked example to write:** Design an information kiosk that reacts if the player re-enters mid-session.
- **Assessable practice:** Trace a repeated action and test correct recovery from interruption.

## 5. Evaluate before handing off

- **Observable capability:** Report accessibility, frame constraints and known defects.
- **Teaching blocks:** walkthrough route; frame time; test matrix; packaging
- **Original worked example to write:** Profile an original gallery scene with a deliberately crowded branch.
- **Assessable practice:** Give an agent one bounded repair after the unaided diagnosis; deliver a rechecked scene freeze and one scoped recovery step.
